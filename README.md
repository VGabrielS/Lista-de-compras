# Lista de Compras 🚀

Um projeto com o intuito de facilitar suas compras. Você pode adicionar e/ou remover os produtos da lista de forma eficiente e fácil de usar.

## 📌 Status do Projeto
✅ Finalizado

## 📷 Demonstração
![image](https://github.com/user-attachments/assets/9d54de70-d373-4985-86ec-f2fff046e46e)


## ✨ Funcionalidades
- Adicionar um novo item à lista pelo campo de texto (o campo não aceita números)
- Marcar um item como concluído através do checkbox
- Remover um item da lista pelo botão de lixeira

## 🔧 Tecnologias utilizadas
- HTML5
- CSS
- JavaScript (vanilla, sem frameworks nem build)

## 📁 Estrutura do projeto

```
index.html      Estrutura da página (cabeçalho, formulário e lista)
styles.css      Estilos da aplicação
scripts.js      Lógica de adicionar/remover itens da lista
assets/         Ícones usados na interface
```

## ▶️ Como executar

Por ser um projeto estático (sem build), basta abrir o `index.html` diretamente no navegador ou servir a pasta com qualquer servidor local, por exemplo:

```bash
npx serve .
```

ou, usando a extensão **Live Server** do VS Code, clicando com o botão direito em `index.html` → "Open with Live Server".
